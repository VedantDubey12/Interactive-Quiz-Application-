# Interactive Quiz Application

A browser-based quiz built with HTML, CSS and JavaScript.

## Features

- 5 multiple-choice questions on web development, Python and Git
- One question at a time, with a progress counter and live score
- Instant feedback: the correct answer turns green, a wrong pick turns red
- Final score screen with a message and a "Try again" button
- Works on desktop and mobile

## How it works

The questions live in an array of objects in `script.js` (`q`, `options`, `answer` index). `showQuestion()` draws the current question, `selectAnswer()` checks the choice and updates the score, and `showResult()` shows the final score after the last question.

## Run it

Open `index.html` in a browser. No install needed.
